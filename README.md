## One Word From Grandma

Entrants send exactly one word: the word their grandma would text about AI.
A judge model compares words two at a time and the funniest, most
grandma-like word wins.

This entry's word is **Robit** — grandma's warm, slightly baffled typo of
"robot": the clever machine that talks back, typed the way she hears it.

`main.ts` (Node 22) writes the word to `/output/entry.txt`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
